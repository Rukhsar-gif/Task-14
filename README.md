# Color Palette Generator

A responsive Color Palette Generator created as **Task 14** of my
**Web Development Internship at Veda Technology**.

## 📌 Project Overview

This project is a simple web application that generates a random
palette containing five hexadecimal color values.

Users can click any color swatch to copy its hex code to the
clipboard.

## 🎯 Objective

The objective of this task was to practice:

- Random value generation
- `Math.random()`
- JavaScript DOM rendering
- Event handling
- Clipboard API
- Dynamic UI updates
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Generate a new random palette
- Five color swatches
- Hex color codes
- Click-to-copy functionality
- Clipboard API
- Copy confirmation message
- Responsive design
- Clean card-based interface
